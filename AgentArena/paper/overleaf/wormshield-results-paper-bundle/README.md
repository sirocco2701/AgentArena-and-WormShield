# WormShield Tuned Paper Bundle

This is the clean tuned-only Overleaf package for the paper's results
section.

It keeps one consistent detector story:

- tuned similarity + semantic + payload fusion,
- cross-dataset comparison against DonkeyRail,
- AgentArena branch ablation,
- AI-Worm branch ablation,
- one non-redundant weight-sensitivity figure.

## Main file

- `wormshield_results_tuned_paper.tex`

## Figures folder

- `figures/wormshield-tuned-weight-sensitivity-clean.png`

The main and ablation comparisons are intentionally left as tables in
the paper, so there are no duplicate table-figures in this bundle.
