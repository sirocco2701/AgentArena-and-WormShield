# AgentArena and WormShield

Detecting and Containing AI-Worm Propagation in Multi-Agent 6G Systems.

This repository contains the cleaned research artifact for the AgentArena / WormShield paper.

- `AgentArena/` contains the interactive AI-native worm propagation simulator, the AgentArena observable dataset, paper-facing notes, and the web demo.
- `WormShield/` contains the WormShield evaluation and reproduction scripts for detector training, ablations, baseline comparisons, threshold analysis, and containment replay.

## Repository Layout

```text
AgentArena-and-WormShield/
  AgentArena/
    demo/                         Runnable web demo
    datasets/                     AgentArena and AI-Worm CSV datasets
    experiments/scripts/           Experiment and plotting scripts
    benchmarks/                    Packaged WormShield benchmark helper
    docs/                          Paper-facing notes
    paper/                         Selected paper snippets and figures
  WormShield/
    reproduce_all.py               End-to-end reproduction driver
    wormshield_*.py                WormShield training/evaluation scripts
    donkeyrail_*.py                DonkeyRail baseline scripts
    *_Results/                     Compact retained result summaries
    paper-main-combined-clean.json Clean paper-result bundle
    wormshield-observable-main.csv AgentArena detector dataset snapshot
```

## Quick Start: AgentArena Demo

```bash
cd AgentArena/demo
npm install
npm start
```

Open `http://127.0.0.1:4173`.

The demo can replay local traces without external model keys. If you use hosted model calls, provide the needed API keys through the UI or environment variables.

## Quick Start: WormShield Reproduction

Create a Python environment and install the dependencies:

```bash
cd WormShield
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Run a full reproduction:

```bash
python reproduce_all.py --fresh
```

For a lighter rerun that reuses generated features when present:

```bash
python reproduce_all.py --reuse-features
```

## GitHub Packaging Notes

Large generated caches are intentionally not committed:

- Hugging Face model cache directories such as `hf_cache/`
- Feature cache directories such as `feature_cache/`
- Python bytecode caches such as `__pycache__/`
- Local build/export folders such as `.dist/`
- The local `donkeyrail-test/` checkout, because the paper-facing scripts and compact retained artifacts are included separately

Those folders are either regenerated by the scripts or are local dependency/cache material that is unsuitable for a normal GitHub repository. The original Desktop folders were left untouched.

## Naming Note

The paper-facing names are:

- `AgentArena`: the simulation environment, dataset, and network-evaluation suite.
- `WormShield`: the detector/defense benchmark.

Some filenames and internal variables still contain older names such as `wormlab` or `wormguard` to preserve reproducibility of earlier scripts.
